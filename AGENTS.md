# AGENTS.md

OpenCode 2 terminal plugin that shows CLIProxyAPI quota usage. Bun, TypeScript, Solid with OpenTUI.

Before editing `src/`, `test/`, or the root entry points, read `CODING_STANDARDS.md`.

- Verify with `bun test`, `bun run typecheck`, and `bun script/check-tests.ts`.
- Tautological tests are forbidden; see `CODING_STANDARDS.md`.
- Changes to `src/tui.tsx` also need the end-to-end check in `CODING_STANDARDS.md`.
